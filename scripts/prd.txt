# git-sweep-go: Git Branch Management Tool
Version: 1.0.0
Author: Brannon Lucas

## Overview
git-sweep-go is a command-line tool written in Go that helps developers and teams manage their Git branches more effectively. It provides functionality to identify, analyze, and clean up stale or unnecessary branches while ensuring safety and maintaining a clean Git history.

## Core Requirements

### 1. Branch Analysis
- Identify all local and remote branches in a Git repository
- Determine the age of each branch (last commit date)
- Check merge status (merged/unmerged) of branches
- Analyze branch activity patterns
- Support for multiple remote repositories

### 2. Safety Features
- Never delete protected branches (main, master, develop, etc.)
- Configurable branch protection patterns
- Dry-run mode for previewing actions
- Confirmation prompts for destructive operations
- Backup mechanism for branch references

### 3. Branch Cleanup
- Delete merged branches locally and remotely
- Remove stale branches based on configurable age thresholds
- Clean up branches with no upstream tracking
- Handle orphaned branches
- Support batch operations with filters

### 4. Configuration Management
- TOML-based configuration file
- Configurable branch patterns for protection
- Customizable age thresholds for staleness
- Remote repository settings
- Branch naming conventions

### 5. User Interface
- Interactive CLI with clear prompts
- Color-coded output for different branch states
- Progress indicators for long operations
- Detailed logging of all actions
- Help documentation and examples

### 6. Git Integration
- Robust Git command execution
- Error handling for Git operations
- Support for Git credentials and authentication
- Handle different Git versions
- Repository state validation

### 7. Performance
- Efficient handling of large repositories
- Concurrent branch processing where possible
- Caching of Git command results
- Progress tracking for long-running operations
- Resource usage optimization
